Start on your Mac

Keep all the extracted project files together. Open this complete version in a fresh folder.

1

Check Python

SILC uses Python 3.11, 3.12 or 3.13. If you need it, install Python 3.13 from the official Mac downloads.

No npm command or Node installation is needed to run this project.

2

Drag the launcher into Terminal

Open Terminal. Type bash, then press the space bar once.

Drag start.sh from the extracted folder in Finder into Terminal. Its full path will appear after bash .

Press Return.

This works from any Terminal folder. You do not need to type cd.
3

Wait for the browser to open

The first run installs dependencies. Keep the internet connected and wait for setup to finish.

The app opens automatically. If it does not, open the local address printed in Terminal, usually http://127.0.0.1:8000.

If that port is busy, the launcher chooses another between 8000 and 8005.

Keep Terminal open while using SILC.
To stop it, click Terminal and press Control+C.
Already inside the folder in VS Code?

Open Terminal → New Terminal. Confirm the terminal is in the project folder, then run:

bash start.sh

A plain cd moves you to your home folder. If you are unsure where you are, use the drag-and-drop method above.

Can I double-click a launcher?

You can try start.command. If macOS does not open it, use the Terminal method above with start.sh.

If something does not start

“start.sh: No such file or directory”

Terminal is looking in a different folder. Type bash and drag the actual start.sh file from Finder into Terminal, then press Return.

“package.json” or “npm run dev” error

Start this project with bash start.sh. Its frontend is served by Python and does not need an npm build.

Python is missing or unsupported

Install Python 3.13, close and reopen Terminal, then run the launcher again. Versions 3.11–3.13 are supported by this package.

Dependencies cannot download

Check your internet connection and rerun the launcher. Keep the exact final error message if it still fails.

Browser says it cannot connect

Check that Terminal is still running SILC. Use the exact local address it prints; the port may be 8001 instead of 8000.

All six ports are busy

Stop an earlier SILC Terminal with Control+C, then rerun the new launcher. Other processes are never stopped automatically.

A saved note seems missing

Notes belong to the same browser, local address and dataset. Changing ports or clearing browser data changes the available storage. Export important assessments.

YOUR REASONING WORKFLOW

Understand every flag

Each case explains its observation, trigger, confidence, missing evidence, alternatives and next checks.

Model explanations have their own small Reasoning tab. Click a citation to open its matching evidence.

A score ranks review priority. It is not an attack probability.

Try AI when you are ready

Start with Offline briefing. It uses a clear rule template and works immediately without an account.

For a local model, install and open Ollama. In a second Terminal window, run:

ollama pull gemma3:4b

Wait for the download. In SILC, choose AI briefing → Ollama (local), select one finding and generate.

The model uses your Mac's memory and processing. Cloud providers require your own API setup and may charge for usage.

See docs/AI_SETUP.md in VS Code for provider settings and troubleshooting.

What stays saved?

Saved assessments stay in this browser and local address. Model explanations and unsaved drafts last for this page session.

Export before reloading if you want to keep the current model explanation. Uploaded CSVs expire after an hour, eviction or server restart.

Use synthetic or sanitized data. Keep private API keys and confidential logs out of GitHub.
